## 👨‍💻 About Me

Hey, I'm **Utkarsh Dubey**, an Integrated MCA student, developer, and researcher who enjoys exploring the intersection of software engineering, artificial intelligence, and reliable systems.

I like turning complicated ideas into practical software, experimenting with new technologies, and understanding why things work instead of merely making them work once.

- 🔭 **Currently building:** AlumConnect, a multi-tenant alumni networking and mentorship platform.
- 🧠 **Researching:** AERIS, a lightweight, deterministic reliability intelligence engine for event-driven microservices.
- 🌱 **Learning & exploring:** Data Structures and Algorithms in C++, full-stack engineering, AI/ML, and system design.
- 🛠️ **Building with:** React, Python, FastAPI, MongoDB, SQL, and modern development tools.
- 🔬 **Interested in:** AI-powered applications, observability, backend architecture, developer tools, and data science.
- 🤝 **Open to:** Meaningful open-source contributions, research collaborations, and projects that solve real problems.
- ⚡ **My philosophy:** Understand the architecture first. Write the code second. Debug everything anyway.

> I don't just want to build applications. I want to understand the systems underneath them.
